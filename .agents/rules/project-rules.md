# ПРОЕКТНЫЕ ПРАВИЛА — Лендинг завода "Ориент" (андезитные блоки, брусчатка)

## О ПРОЕКТЕ
Лендинг + мини-каталог (10-15 товаров) для производителя стройматериалов
из Приморского края. Цель — сбор заявок, НЕ онлайн-продажа.

## СТЕК (не менять без согласования)
- Astro (статическая генерация)
- React — только как "острова" для интерактива (форма, сайдбар-фильтр)
- Tailwind CSS — единственный способ стилизации
- FormSubmit — backend формы заявки (НЕ Supabase, НЕ БД)
- Данные товаров — Astro Content Collections (src/content/products/)

## СТРУКТУРА ПРОЕКТА
- src/pages/ — index.astro, catalog.astro, catalog/[slug].astro, contacts.astro
- src/components/ — раздельно .astro (статика) и .jsx/.tsx (интерактив)
- src/layouts/BaseLayout.astro — общий layout с SEO-компонентом
- src/content/products/ — товары (Markdown/JSON), схема через content.config.ts
- Никогда не хардкодить данные товаров внутри JSX/Astro-разметки

## ЖЁСТКИЕ ЗАПРЕТЫ (без явного запроса от меня)
- НЕ создавать корзину, избранное, регистрацию пользователей, оплату онлайн
- НЕ подключать Supabase или любую БД — формы только через FormSubmit
- НЕ добавлять новые npm-зависимости без предварительного согласования
- НЕ менять структуру папок и архитектуру без подтверждения
- НЕ переписывать существующий рабочий код без явного запроса на рефакторинг
- НЕ использовать инлайн-стили и отдельные CSS-файлы — только Tailwind

## SEO — ОБЯЗАТЕЛЬНО НА КАЖДОЙ СТРАНИЦЕ
- Уникальный Title с упоминанием продукта и региона (Владивосток/Приморский край)
- Meta Description, Open Graph теги (og:title, og:description, og:image)
- Один H1 на страницу, логичная иерархия H2-H3
- Alt-теги на всех изображениях, семантические теги вместо избыточных div
- ЧПУ-адреса страниц (например /catalog/andezit-blok-stenovoy)

## ФОРМА ЗАЯВКИ (FormSubmit)
- Отправка через AJAX-режим (fetch на https://formsubmit.co/ajax/почта),
  без перезагрузки страницы
- Обязательные скрытые поля: _subject, _next (не обязателен при AJAX), _honey
- Поля формы: имя, телефон, интересующий товар (опционально), комментарий
- После отправки — показывать сообщение "Спасибо, заявка отправлена" внутри страницы
- Все input/textarea должны иметь атрибут name — иначе FormSubmit их проигнорирует

## СТИЛЬ КОДА
- Комментарии в коде — на русском, имена переменных/функций — на английском
- Компоненты небольшие и переиспользуемые, разделение по ответственности
- Единый нейминг файлов: kebab-case для .astro, PascalCase для React-компонентов
