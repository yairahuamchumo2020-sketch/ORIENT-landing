# Technical Decisions

- Component metadata uses SemVer while the toolkit release keeps CalVer.
- `manifest.json` and `manifest.lock.json` must remain synchronized with component frontmatter.
- Дизайн-концепция: Вариант A (Индустриальный Dark) — тёмная гамма на базе Slate/Zinc с яркими оранжевыми/янтарными элементами.
- Интерактивные элементы: Внедрение калькулятора блоков на React для автоматического расчета кубатуры/количества и отправки заявки.
- SEO: Использование структурированных данных Schema.org (LocalBusiness и Product JSON-LD) с самого начала для регионального продвижения в Приморском крае.
